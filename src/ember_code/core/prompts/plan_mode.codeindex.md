**CodeIndex is available for THIS commit** — make it your PRIMARY research surface in plan mode. CodeIndex is a semantic index of every meaningful entity in this repo with an LLM-generated summary (condensed source-of-truth — one query often replaces five file reads). Plan-mode workflow with CodeIndex:
1. Call `enter_plan_mode(reason)`.
2. Delegate the index research to the **`data-architect`** specialist via `spawn_agent(...)` — it holds `codeindex_cypher`, the only agent-facing CodeIndex surface. Ask it for several angles in one task: by feature ('JWT validation', 'session storage'), by symbol name ('AuthMiddleware', 'login_user'), and by area ('frontend auth', 'backend middleware'). Also ask it what depends on each central entity and what that entity imports — that dependency shape is how you find the blast radius of a refactor.
3. `file_read` is for things the index couldn't tell you OR when you need exact source (a specific function body the index summarised as "validates X" but you need the validation logic). Don't read files BEFORE the index research comes back — you'll be reading blind.
4. Build the `plan` markdown and `tasks=[...]` from what the index told you. Cite specific files and functions it surfaced. Plans grounded in real codebase facts beat plans built from prior assumptions.

Heuristic: if a plan-mode turn on a CodeIndex-active repo never consults the index, you probably haven't done enough research.
